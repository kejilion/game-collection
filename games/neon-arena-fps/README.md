# 霓虹竞技场 · NEON ARENA

3D 第一人称多人在线混战射击游戏。一个 URL，多个客户端直接进入同一房间开打 —— 无需注册、无需下载。

- **服务端**：Node.js（express + ws），单房间权威服务器，所有伤害/拾取/购买均在服务端判定
- **客户端**：Three.js 第一人称，全部模型/贴图/音效程序化生成，零外部资源
- **持久化**：排行榜与玩家档案（金币/外观，按昵称）保存在 `data/profiles.json`

## 打击感

命中反馈是一整条链路，不是单加个音效：命中瞬间视角会朝攻击方向弹一下（弹簧阻尼式回弹，比纯随机抖动更"扎实"）；近战命中额外给一记前顶力道，铁锤最沉、小刀最脆；被打的玩家/BOSS 会有短促的后仰位移或挤压反应；子弹打空/打墙会在终点补一个环境命中火花，不再是"消失了事"；暴击/爆头的准星弹出动画单独放大；音效上给命中/爆头叠加了低频瞬态增加"肉感"，近战命中按武器分量级。这些全是客户端表现层的东西，服务端只多广播了一个武器类型字段，伤害计算和命中判定完全没动。

## 玩法

- 随机地点出生，初始只有**拳头**；死亡后换地点重生（重生有 2.5s 保护）
- **死亡舔包**：死亡时枪械、剩余投掷物和非默认近战武器会散落在附近，所有玩家走近即可自动拾取并替换对应槽位；掉落保留剩余弹药，15 秒后消失
- **场地尺寸**：整体战场扩为 **96x96**（外墙 ±48），没有内环分隔，外围空间直接并入主战场。
- **地形**：两处高地平台（台阶可上）搭配外围掩体，可卡点也可被手雷洗地；**红色油桶可被打爆**，殃及半径 4.5m 内所有人（会连锁！），30~45s 后重生
- **昼夜交替**：10 分钟一昼夜，清晨/白天/黄昏/深夜光照与天空实时变化，夜晚霓虹灯柱亮起（左上角有时段指示）
- 场内 18 个拾取点自动刷新三类物品（走近自动拾取）：
  - **武器**：小刀 / 长刀 / 铁锤 / 手枪 / 机枪 / 狙击枪 —— **有限备弹**，越强的枪备弹越少（手枪 156 发 / 机枪 360 发 / 狙击 35 发），打空当前匣自动换弹（消耗备弹），**备弹打光会提示"用光了"，玩家自己去武器点换新枪**（空枪留在手里）；狙击枪右键开镜
  - **投掷物**（三选一，拾取替换，携带有限个）：💣**手雷** ×5 范围爆伤（冷却 2s）；🔆**闪光弹** ×6 致盲正对爆点的敌人，越近越正对白得越久，视线被墙挡住免疫（冷却 1.6s）；💨**烟雾弹** ×8 15 秒视野遮蔽，烟中名牌隐藏、手机端辅助瞄准同样失效（冷却 1.6s）。用光同样提示、自行补给
  - ⚙️ **补给方式**：不单独捡子弹——**拾取任意武器点即弹药满血**（同款枪=补弹，新枪=换枪满弹；投掷物点补满个数）
  - **装备**：医疗包(+50血) / 防弹衣(+50甲) / 疾风靴(永久+10%移速，最多3层)
  - **状态道具**：⚡疾速 / 🔥狂暴 / 💥暴击 / 👻隐身 / 🧟暴走丧尸(只能近战·伤害翻倍·吸血) / 🦘弹跳 / 🛡️护盾
- **四种特色 BOSS** 随机降临（同场仅一只），击杀得金币 + 满血 + 随机增益，助攻也有金币：
  - 🪨 **熔岩魔像**：近战重击 + 火球（200🪙）
  - 🗡️ **暗影刺客**：高速突进，会闪现到你身后、周期隐身（180🪙）
  - 🤖 **钢铁暴君**：1400 血重装机体，弹幕连射 + 三连火箭（280🪙）
  - 💀 **虚空巫妖**：追踪法球 + 脚下紫圈延迟爆破，看到圈快跑！（220🪙）
- **神秘商人**（西北侧摊位，按 E）：金币购买头部/面部/背部/武器光效等外观装饰；**商店内置 3D 试衣间**，悬停即试穿；全场可见、按昵称永久保存
- **击杀奖励**：+100 分 +25 金币 +15 血；连杀有全场播报
- **聊天**：回车发送；**排行榜**：按 Tab（实时榜 + 历史榜，击杀数优先，并列时**连杀**更高者靠前）。实时榜末列显示当前连杀、历史榜显示历史最高连杀，主菜单也展示历史榜
- **观战模式**：菜单进入或阵亡后选择，自由飞行视角（WASD+空格/C，滚轮调速），按 F 跟随玩家（←/→ 切换，默认第三人称，V 切第一人称），回车随时加入战斗
- **设置**（ESC）：背景音乐、音效开关，鼠标灵敏度，视角切换

## 移动端 / 跨端公平性

手机浏览器打开同一个 URL 可以和电脑玩家同场竞技，专门做了以下适配，目标是**手机不是弱势群体**：

- **触屏操作**：左下角虚拟摇杆（浮动式，触点落下即生成）负责移动；屏幕其余区域拖拽控制视角；右下角圆形按钮负责开火(◎，持枪自动挂机枪连发)/跳跃(⤒)/狙击镜(🔭，持狙击枪时才出现)；右上角 ☰设置 🏆排行榜 💬聊天。武器栏（HUD 下方三个格子）改为点按切换，再点一次已激活的枪械格 = 换弹，省掉一个按钮
- **子弹磁吸辅助瞄准**：仅触屏客户端生效——开火方向如果 7° 锥角内有敌人，会在客户端本地朝目标中心柔性纠偏最多 35%（不是 100% 锁定），用来补偿手指精度天生低于鼠标这件事；桌面端这段代码完全不跑，服务器判定逻辑对两端一视同仁，没有任何后门
- **画质自适应**：按设备算力分三档（阴影分辨率 2048/1024/512、抗锯齿开关、像素比上限），持续帧率过低还会自动砍阴影救场。**红线是视距和雾距离永远不缩短**——看得多远、看得见多远的敌人，两端必须完全一致，画质分级只动阴影/抗锯齿这类纯观感开销
- **轻量背景音乐**：程序化合成、零音频文件；标签页切后台自动停止音乐调度省电；移动端默认精简和弦垫与镲片密度（`lite` 模式），进一步降低同时发声的振荡器数量
- 安全区适配（刘海屏）、`touch-action` 防止游戏区域被系统手势/双指缩放打断、面板加了 × 关闭按钮（桌面也能用）

用 `?touch=1` / `?touch=0` 可以在任意设备上强制切换触屏 UI 便于调试，`?quality=high|medium|low` 强制画质档位。

## 本地运行

```bash
npm install
npm start        # 默认 http://localhost:3000
```

浏览器打开 `http://localhost:3000`，多开几个标签页即可体验联机。

## Docker 部署

```bash
# 方式一：docker compose（推荐，含数据卷与自动重启）
docker compose up -d --build

# 方式二：手动构建
docker build -t neon-arena-fps .
docker run -d --name neon-arena \
  -p 3000:3000 \
  -v /opt/neon-arena/data:/app/data \
  --restart unless-stopped \
  neon-arena-fps
```

部署完成后，把 `http://服务器IP:3000` 发给朋友即可同场竞技。`/health` 返回在线人数等状态，可接入监控。

### 反向代理（可选，启用 HTTPS/域名）

WebSocket 与页面同端口同路径，Nginx 需开启 Upgrade 透传：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

页面走 HTTPS 时客户端会自动使用 `wss://`，无需额外配置。反代不在本机回环地址时，服务端需设置 `TRUST_PROXY=1` 才会信任 `X-Forwarded-For` 并按真实玩家 IP 做封禁。

## 反作弊

服务端权威 + 通用反作弊引擎，默认开启。所有伤害、位移、拾取、购买均由服务器裁决，客户端消息只作"请求"。

- **三通道证据**：移动、战斗、完整性分别计分和衰减；移动异常快速衰减、可回拉/警告/踢出，但不能单独直接封禁
- **移动校验**：瞬移当场回拉、加速/飞天/穿墙漏桶判定（容忍网络抖动，其他玩家永远看到合法位置）
- **网络尖峰豁免（防误封）**：包间隔异常大（丢包/卡顿恢复）时，那一包只回拉位置、**不计违规分**——卡顿玩家不被冤枉，外挂即便刻意慢发也照样被回拉、超豁免额度后照样被抓。瞬移阈值随包间隔动态放大，弹跳/疾速道具的高度和速度边界也做了宽限，人多网络波动不再误触封禁。
- **射速校验**：冷却时序收口，连点宏/射速外挂无效
- **限速**：分消息类型令牌桶直接丢弃洪泛包，只记审计事件、不叠加处罚分
- **WS 连接突刺封禁**：同一 IP 在 1 秒内涌入大量 WebSocket 连接会直接写入反作弊 IP 封禁，并关闭该 IP 已建立的连接
- **战斗统计**：PvP 爆头率/命中率/甩枪、未开镜狙击、每杀耗弹和三档击杀速度联合分析；BOSS、怪物和场景物件不计入命中率
- **慢速外挂辅助识别**：仅采样实时榜头部或已有可疑分玩家；重复“隔墙持续贴准→首次露头快速命中”与长期高 K/D/击杀效率必须互相印证，单凭高战绩不处罚
- **连杀辅助证据**：在线至少 3 人时，15/20/30 连杀的辅助分累计到 2/5/10 分；辅助分不随时间衰减，死亡清零，单独无法达到警告线
- **阶梯处置**：纠正 → 警告 → 踢出 → 封禁（IP+昵称；纯移动异常需 24h 内 6 次踢出才升级，其他异常 3 次；踢出与封禁都会清除完整玩家档案）

`GET /health` 暴露 `anticheat`、`audit` 与 `wsGuard` 实时指标（分通道最高分、规则/处置计数、审计队列、连接突刺封禁数等）。最近 500 条反作弊事件写入 `data/anticheat.json`；完整事件及 5 分钟玩家会话汇总按天写入 `data/anticheat-audit-YYYY-MM-DD.jsonl`，默认保留 30 天，IP 只保存稳定匿名哈希。运行 `npm run ac:report -- --days 7 --data-dir ./data` 可生成离线报告。设 `AC_MODE=off` 可关闭惩罚（用于压测/调试，冷却与数值等功能校验仍生效）。

引擎已抽象为**零依赖、可移植的通用库**（`server/anticheat/`），可直接复制到任何 Node 多人对战服务器复用，接入方法、API 与调参 checklist 见 [server/anticheat/README.md](server/anticheat/README.md)。

## 聊天内容过滤

- 服务端统一过滤聊天内容，客户端无法绕过；命中内容只替换为 `*`，不会触发反作弊加分、踢出或封禁。
- 昵称命中词库时拒绝加入，避免敏感昵称写入玩家档案和排行榜。
- 词库位于 `server/sensitive-words.txt`，启动时一次加载；匹配自动兼容大小写、全角字符以及插入空格或标点的规避写法。
- 玩家聊天在过滤后写入 `data/chat-history.jsonl`，内存保留最近 200 条，新连接回放最近 40 条；不会落盘保存被屏蔽前的原文。
- 词库应保持保守，避免加入单字、`sb` 等容易误伤正常文本的短词；修改词库后需要重启服务。
- `/health` 的 `chatFilter` 和 `chatHistory` 字段仅返回词条数、命中数和历史条数，不暴露聊天内容。

## 配置

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | 3000 | 监听端口 |
| `DATA_DIR` | `./data` | 排行榜/档案/封禁记录存储目录 |
| `AC_MODE` | `on` | 设 `off` 关闭反作弊惩罚 |
| `AC_AUDIT_MODE` | `on` | 设 `off` 关闭追加式反作弊审计 |
| `AC_AUDIT_RETENTION_DAYS` | `30` | 按天审计文件保留天数 |
| `AC_RULE_VERSION` | `2026-07-16-v1` | 写入审计记录的规则版本标识 |
| `DEPLOY_VERSION` | `local` | 写入审计记录的部署版本标识 |
| `CHAT_FILTER_MODE` | `on` | 设 `off` 关闭聊天及昵称敏感词过滤 |
| `CHAT_FILTER_FILE` | `server/sensitive-words.txt` | 自定义 UTF-8 词库路径，一行一个词 |
| `TRUST_PROXY` | `off` | 设 `1`/`true` 后信任反向代理传入的 `X-Forwarded-For` / `X-Real-IP` |
| `WS_FLOOD_MAX_PER_SECOND` | 12 | 同一 IP 在 1 秒窗口内允许的最大 WS 连接数，超过即封禁 |
| `WS_FLOOD_BAN_MINUTES` | 60 | WS 连接突刺触发后的基础 IP 封禁分钟数，重复封禁会按反作弊历史升级 |
| `WS_FLOOD_WINDOW_MS` | 1000 | WS 连接突刺检测窗口 |
| `IP_MAX_CONCURRENT` | 4 | 同一 IP 最大并发 WebSocket 连接数 |

游戏数值（武器伤害、BUFF 时长、BOSS 属性、商店价格、地图布局等）集中在 [server/config.js](server/config.js)，服务端加入时会把配置下发给客户端，改一处两端同步生效。

### 枪械精度

- 手枪保持稳定中距离定位；机枪首发散布较低，持续扫射约 2.3 秒后达到最大扩散；狙击枪仅开镜时保持高精度。
- `spread` / `scopedSpread` 使用弧度表示圆形散布锥，`moveSpreadMul` 控制移动惩罚，`bloomPerShot` / `maxBloom` / `bloomDecay` 控制持续射击扩散。
- 触屏辅助瞄准先修正基础瞄准方向，再应用与电脑端相同的武器散布，不会抵消随机扩散。
- 准星扩散直接读取同一动态扩散状态，并按秒衰减，因此不同帧率下表现一致。

  index.js       HTTP + WebSocket 入口、循环调度、反作弊接线
